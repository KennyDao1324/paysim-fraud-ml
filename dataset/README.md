# Dataset

Download PaySim from the [official Kaggle dataset page](https://www.kaggle.com/datasets/ealaxi/paysim1).
The data is licensed CC BY-SA 4.0. Place the extracted file at:

```text
data/raw/PS_20174392719_1491204439457_log.csv
```

The raw CSV is ignored by Git. Run `python scripts/download_paysim.py` after configuring Kaggle credentials.
